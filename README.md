# Infoseg Qualidade — SUSPeritos

Protótipo acadêmico do Caso 1, PBL Eixo 3.

Todos os resultados são fictícios, inclusive os valores associados aos nomes reais das 27 UFs. Não há conexão com bases governamentais.

Versão final compatibilizada em 22/10/2026 com os entregáveis do grupo. IQD-base = 0,35 × CT + 0,30 × CC + 0,20 × TM + 0,15 × CN. O bônus PPE/API permanece a pactuar.

Hospedagem estática: HTML, CSS e JavaScript. Ativar GitHub Pages na branch main, pasta / (root). O arquivo .nojekyll dispensa processamento pelo Jekyll.

O formulário mantém respostas apenas durante a sessão e permite exportar CSV. Não existe banco de dados compartilhado.
